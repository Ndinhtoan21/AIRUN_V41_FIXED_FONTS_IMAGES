# Deploy AIRUN V7.3

1. Giải nén V7.3 và copy đè toàn bộ file vào repo AIRUN hiện tại.
2. Không đổi hai Rewrite Rule Weather/Air trên Render.
3. Commit và push branch `main`.
4. Chờ Render Auto Deploy xong.
5. Hard refresh (`Ctrl + Shift + R`) hoặc đóng/mở lại tab trên điện thoại.
6. Khi không có Mapbox token, góc bản đồ phải hiện `OpenFreeMap · MapLibre`.
