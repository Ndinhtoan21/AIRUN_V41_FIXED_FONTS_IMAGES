# AIRUN V7.1

Bản cập nhật tập trung sửa bản đồ khi chạy GPS và độ rõ route.

## Điểm chính
- Mapbox được dùng trực tiếp trong GPS Tracker nếu đã kết nối token.
- Bản đồ tự fit/resize khi mở tracker, đổi kích thước màn hình hoặc nạp cung chạy.
- Route và marker gọn hơn, không che bản đồ.
- Font tiếng Việt trên marker dùng Be Vietnam Pro.

## Deploy
Giữ nguyên Render Static Site và hai Rewrite Weather/Air đang dùng. Thay source, commit và push branch main.
